The mark

One path in, three paths out. The weight of each branch is its probability, and the dot is the decision that was taken. It is the shape of every TypeSafe node in the product, and it is drawn with a single stroke so it survives at 16 pixels.

Color

Cool graphite neutrals carry the interface. Cobalt is the one accent, and it belongs to decision intelligence: the mark, the primary action, and every TypeSafe node share it. Status colors are reserved for run state. Each node category has one hue so a canvas reads at a glance.

Principles for the interface

These are the rules the app follows. When a screen breaks one, the screen is wrong.

Numbers are monospacedAnything a model or a clock produced is set in JetBrains Mono with tabular figures, so columns of probabilities line up.
Cobalt means decisionThe accent is spent on decision intelligence and the primary action. Nothing else is blue.
State is a border, not a fillRunning, waiting and failed nodes change their outline. Fills stay neutral so the canvas never shouts.
Configuration lives in the inspectorA node shows its name, purpose, provider and last result. Everything else is one click away.
Errors say what to doAn error names the node, the cause, and the next step. It never apologizes and never says "something went wrong".
Empty states inviteAn empty canvas offers the palette and the AI builder. An empty run list offers a first run.
