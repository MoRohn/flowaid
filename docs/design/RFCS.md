# flowaid — RFC index for `CONTRACTS.ts`

`CONTRACTS.ts` is frozen; it changes only through an accepted RFC (`docs/rfcs/NNNN-<slug>.md`, template `docs/rfcs/0000-template.md`) and a version bump of `@flowaid/workflow-core`. This file is the index. Every entry below was raised by the 2026-09-22 design review (`docs/review/*.md`, `docs/UPGRADE_PLAN.md`); each names the finding that proves the contract wrong or incomplete, the exact change, and the plan item that implements it. Until an RFC is **accepted**, the design documents describe the change and `CONTRACTS.ts` is unchanged; the implementing item applies the edit and bumps the package version. RFC-0013…0016 were raised on 2026-09-23 by the Jev engineering gap analysis (`JEV_ENGINEERING.md` §2.4, gap ids `jev-*`) and are implemented by track J of the upgrade plan.
